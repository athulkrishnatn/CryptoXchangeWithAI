🚀 CryptoVeille
CryptoVeille is an AI-powered, real-time cryptocurrency monitoring platform that blends live market data, smart UI design, and conversational assistance to deliver fast, insightful crypto analysis.

🌐 Live Demo: CryptoVeille – Try it out!

🧠 Features
🔍 Track 100+ Cryptocurrencies Live
Real-time updates from the Binance API using WebSockets.

🎨 Sleek, Modern UI
Built with React, Tailwind CSS, and Aceternity UI, animated with Framer Motion.

📊 Interactive Charts
Powered by Chart.js to visualize price trends dynamically.

🧾 Personal Watchlist
Add your favorite coins for quick access and monitoring.

🖼️ NFT Market Insights
Explore live NFT data and trends.

🤖 Conversational AI Assistant
Get instant market analysis and answers with Google Gemini LLM.

🔐 Authentication & Security
Secure login using JWT tokens.

🛠️ Tech Stack
Frontend: React, Tailwind CSS, Aceternity UI, Framer Motion

Backend: Node.js, Express, MongoDB

Authentication: JWT

Real-Time Data: WebSocket, Binance API

Charts: Chart.js

AI Integration: Google Gemini LLM API
